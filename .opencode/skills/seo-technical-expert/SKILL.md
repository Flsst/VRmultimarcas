# Technical SEO Expert

Implement SEO from real project information. Never fabricate business facts for schema or metadata.

## Page fundamentals

Ensure:
- unique meaningful title;
- useful meta description;
- one clear primary H1;
- logical heading hierarchy;
- descriptive link text;
- crawlable content;
- meaningful image alt text where appropriate.

## Technical

When relevant to the stack/project:
- canonical URL;
- robots directives;
- sitemap;
- Open Graph;
- social card metadata;
- favicon/app metadata;
- language declaration;
- structured data.

## Structured data

Use only schema types justified by real information.
Do not invent:
- ratings;
- review counts;
- prices;
- availability;
- addresses;
- opening hours;
- organizations or credentials.

## Local businesses

When real data is available, make location/service-area information easy for users and search engines to understand.
Maintain consistent business name/contact details.

## Content

Write for users first.
Avoid keyword stuffing.
Use naturally descriptive headings and service/product terminology.

## SPA/SSR awareness

Understand how the current framework outputs metadata and page content.
Prefer server-rendered or statically rendered critical landing-page content when the stack supports it.

## Review

Check the final rendered page, not just source files, when possible.
